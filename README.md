
# Sentinel - Landing Salud Ocupacional CR

## Despliegue en Vercel
1. Crea cuenta en https://vercel.com/ y elige **New Project**.
2. Sube este proyecto (o impórtalo desde GitHub).
3. Acepta la detección automática de **Next.js** y despliega.
4. Sube tus imágenes reales a `public/images/` con los nombres indicados.
5. Listo.

## Formularios
- Conectado a Formspree (`mpwogyab`).

## Personalización
- Cambia textos en `app/page.tsx`.
- Reemplaza `/public/logo.png` y `/public/favicon.png`.
